# Finexy 旧版 Web UI 设计归档

归档日期：2026-09-04。

此目录保存 2026 年 8 月形成的旧设计系统、HTML 原型和界面参考截图。它们包含紫色/荧光色、软玻璃、像素狐狸游戏化、异形面板等已经停止使用的方向。

这些文件仅用于历史追溯，不是当前产品规范，不得用于生成新页面或判断视觉回归。当前唯一 UI/UX 基线是 `docs/UI_UX_DESIGN.md`；真实 token 以该文档列出的 Web 与 Android 源码为准。

- `design-system-ai-bookkeeping/`：旧 Master、V2 soft-glass、页面覆盖和 HTML 原型。
- `reference-captures/`：历史截图和 UI 自动化 YAML，本地归档，不参与构建。
