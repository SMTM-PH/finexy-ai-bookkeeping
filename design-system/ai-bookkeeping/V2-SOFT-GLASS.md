# 栗子记账 V2 — Soft Glass Wallet

> 状态：设计基线，优先于 `MASTER.md` 的视觉与结构规则；尚未进入生产迁移。

## 1. 产品命题

栗子记账不是传统财务后台，而是个人的“资金驾驶舱”。首页只回答三个问题：今天记了吗、钱在哪里、最近发生了什么。复杂设置和低频管理退出主导航。

## 2. 核心结构

主导航压缩为五个工作区：

1. **今日**：快速记账、待处理、预算和资产摘要。
2. **流水**：月历与日期流水，筛选和编辑交易。
3. **钱包**：微信零钱、支付宝、银行卡、信用账户和现金。
4. **资产**：可折旧商品、持有成本与出售记录。
5. **洞察**：固定月报、趋势、预算与 AI 报告历史。

分类、标签、模板、定时交易、导入导出、用户设置和应用设置统一进入右上角“控制中心”。它们不再长期占用左侧导航。

## 3. 全局布局

```text
┌─────────┬─────────────────────────────────────────────────────┐
│ 浮动轨道 │  顶部状态 Dock：日期 / 今日状态 / 快速记账 / 通知  │
│         ├─────────────────────────────────────────────────────┤
│  今日   │                                                     │
│  流水   │                 当前工作区                          │
│  钱包   │                                                     │
│  资产   │                                                     │
│  洞察   │                                                     │
│         │                                      浮动 AI 入口   │
└─────────┴─────────────────────────────────────────────────────┘
```

- 桌面端侧轨宽 88px，默认只显示图标与短标签；悬浮或键盘聚焦（`:hover`/`:focus-within`）时展开到 228px，并提供「固定展开」开关。
- Dock 常驻顶部，高斯模糊其下内容；内部不再嵌套玻璃卡片，只用细分隔线；通知中心与快速记账位于 Dock 右侧。
- 内容区采用 12 列自适应网格，但卡片大小由信息重要性决定，不做平均宫格。
- 1240px 以下侧轨收缩为底部 Dock（含中央快速记账 FAB）；快速记账始终保留，AI 浮动入口同步上移至底部 Dock 上方。

## 4. 首页信息顺序

1. **今日记账台**：一句话录入是主操作，上传账单和购物截图是次操作；空态给出可点击的示例短语。
2. **待处理收件箱**：仅在存在异常或缺失信息时出现，完成后消失。
3. **资金脉搏**：净余额总览卡（深色软质面板，内嵌最多三个最近账户与「转账 / 记一笔」快捷操作）、本月支出、本月预算；与上月对比。
4. **持有资产**：突出每日成本、已使用天数与账面价值。
5. **洞察胶囊**：按需生成月报，并展示最近一次报告结论；不自动调用 AI。

> 钱包速览不再单独成区，并入净余额总览卡；账户行必须直读余额，并以状态点区分「已核对 / 待核对」（参考 Finexy 的 Total Balance 内嵌 Wallets 结构）。

## 5. 关键使用逻辑

### 快速记账

`输入一句话 → 本地规则优先匹配 → AI 仅补齐缺失字段 → 行内确认 → 正式入账`

- 字段完整时直接入账，不打开长弹窗。
- 字段缺失时在输入框下方展开紧凑确认条，而不是打开全屏对话框。
- 同一句输入失败后保留上次识别结果；重试只处理失败步骤。

### 账单导入

`上传 → 本地 OCR → 批量预处理 → 自动入账 → 仅异常进入收件箱 → 删除原文件`

- 导入进度出现在全局通知中心。
- 异常条目允许继续入账、编辑或删除。

### 流水

- 默认完整月历；点击日期后，月历压缩到左侧 42%，右侧显示当日流水。
- 同月切换日期不重复请求数据。
- 交易编辑使用右侧抽屉，保持日期上下文。

### 钱包

- 账户以实体卡片展示，品牌图案承担识别，余额信息保持最高对比。
- 点击卡片后在同页显示详情、余额构成与最近流水。
- 账户间转账只产生一条资金流转关系，不计入收入或支出。

## 6. 材质系统

玻璃只表达“悬浮层级”，柔性拟态只表达“可以触摸”。两者不得混用在同一个信息层级上。

| 层级 | 材质 | 用途 |
|---|---|---|
| G0 | 雾面画布 | 页面背景和环境色 |
| G1 | 软质面板 | 普通卡片、统计区、表单组 |
| G2 | 透明玻璃 | Dock、侧轨、浮动工具、抽屉 |
| G3 | 聚焦玻璃 | 对话框、命令面板、异常确认 |

柔性拟态状态：

- 默认：双向柔和外阴影，顶部冷白高光。
- 悬浮：轻抬 2–3px，阴影扩散，不放大。
- 按下：切换为内阴影，位移 1px。
- 禁用：取消高光与阴影，保留 56% 文字对比度。

签名纹理（参考 Finexy 的 hatch 语言）：

- 斜纹 `repeating-linear-gradient(-45deg, …)` 只表达「负空间」：预算条的剩余额度、折旧条的未折旧部分、洞察图表的支出柱。
- 实色表达已发生（已用、已折旧、收入）；斜纹表达尚可动用（剩余、未折旧、支出）。两者不得互换。
- 深色总览卡是 G1 的深色变体（软质面板而非玻璃），仅用于净余额总览，与 Dock 的深色玻璃呼应；同屏最多一张。

## 7. 视觉令牌

| 名称 | 色值 | 用途 |
|---|---|---|
| Ink | `#172033` | 主要文字 |
| Muted | `#657089` | 说明和元信息 |
| Mist | `#EDF0F9` | 主画布 |
| Cloud | `#F9FAFF` | 面板高光 |
| Iris | `#7568F8` | 主行动和焦点 |
| Ice | `#45B8C6` | 信息、转账和辅助图表 |
| Mint | `#72D6BD` | 成功、余额确认 |
| Coral | `#ED7184` | 异常和危险操作 |

- 中文正文：微软雅黑 UI / 苹方 / Noto Sans CJK SC。
- 展示标题：站酷庆科黄油体，仅用于首页短标题。
- 金额与日期：JetBrains Mono Variable，启用等宽数字。
- 正文最小 14px；功能标签最小 12px；装饰英文不得承担关键信息。

## 8. 动效

- 页面切换：280–360ms，淡入与 16px 水平位移。
- 卡片交互：180–240ms，只改变位移和阴影。
- 记账成功：金额沿输入框收拢为一枚薄荷色确认点，再进入流水。
- 钱包轮播：带轻微景深，不使用连续自动播放。
- 完整支持 `prefers-reduced-motion`，关闭后无信息损失。

## 9. 可访问性

- 所有正文与玻璃背景组合达到 WCAG AA。
- 模糊不可用时退化为不透明浅色面板。
- 焦点环使用 3px Iris 外环，不只依赖颜色区分状态。
- 图表必须提供文字摘要；金额不能仅通过红绿表达。

## 10. 迁移顺序

1. 设计令牌、Dock、侧轨与响应式壳层。
2. 今日首页与紧凑快速记账。
3. 钱包与账户详情。
4. 流水月历和编辑抽屉。
5. 资产与洞察。
6. 控制中心及全部设置页。

每个阶段独立验收后再替换生产页面，旧路由在迁移期间保持可用。
