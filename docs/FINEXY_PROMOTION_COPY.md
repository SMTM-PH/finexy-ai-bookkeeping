终于找到一款真正以“账本”为中心的记账工具｜Finexy

### 正文

一直想找一款适合个人和家庭一起使用的记账工具，最近试用了 Finexy。

它和普通记账 App 不太一样，核心是“账本”：

- 个人可以创建自己的账本
- 家庭可以创建共享账本
- 支持多个账本快速切换
- 可以通过邀请码邀请家人或朋友加入
- 支持所有者、普通成员和只读成员权限
- 共享成员可以直接使用账本账户和分类记账

- 支持 Web、Android、Windows 和 Docker 自托管

我比较喜欢它的设计思路：个人记账、家庭记账、旅行记账、装修预算、存钱目标，都可以用不同账本来管理，数据之间不会混在一起。

如果比较在意数据自主权，也可以自己部署在 NAS 或服务器上。

## 论坛推荐

### 标题

推荐一款适合 NAS 部署的开源记账系统：Finexy，支持家庭共享账本

### 正文

最近在整理个人和家庭账目时，一直想找一套能部署在自己 NAS 上、同时兼顾多人协作的记账系统，于是做了 Finexy。

Finexy 是一个开源、自托管的财务管理系统，提供 Web、Windows 和 Android 客户端。它现在以“账本”为数据中心：一个人可以建立多个账本，家庭成员也可以加入同一本账本共同记录，同时保留清晰的成员权限和数据范围。

![Finexy Web 首页](https://smtm-ph.github.io/finexy-ai-bookkeeping/assets/img/finexy-dashboard.png)

### 为什么要以账本为中心

普通记账软件经常把所有数据放在同一个空间里。个人消费、家庭开支、旅行预算和装修支出混在一起，时间久了很难整理。

Finexy 可以为不同用途分别建立账本，例如：

- 个人生活账本：只记录自己的日常收支；
- 家庭共享账本：邀请家人一起记账；
- 旅行或装修账本：让临时项目的预算和流水保持独立；
- 存钱目标账本：围绕买车、旅行或应急金持续记录进度。

切换当前账本后，首页余额、账户、流水和存钱目标都会使用对应账本的数据，不会把不同用途的记录混在一起。

### 家庭成员怎样一起记账

账本所有者可以生成一次性邀请码。受邀人输入邀请码后，会先看到要加入的账本、邀请人和获得的权限，确认后才会成为账本成员。

目前提供三种角色：

- 所有者：管理账本、成员和账本数据；
- 普通成员：使用共享账户和分类新增流水；
- 只读成员：查看账本数据，但不能记账。

账本详情会集中展示成员数量、账户数量、流水数量、存钱目标以及按币种汇总的账户余额，适合家庭日常开销、共同储蓄和多人项目使用。

### 主要功能


- 收入、支出、转账和余额调整；
- 多账户、分类、标签、模板和组合筛选；
- 月度收支、趋势、分类统计和 CSV 导出；
- 存钱目标与目标资金记录；
- 周期计划到期后进入待确认队列，不会未经确认直接改变余额；
- 多币种账户和汇率换算；
- 可选的 AI 文本识别与中文票据 OCR；
- 登录安全、两步验证、应用锁和加密备份；
- Web/PWA、Windows、Android 与 Docker/NAS 部署。

![Finexy Android 首页](https://smtm-ph.github.io/finexy-ai-bookkeeping/assets/img/phone-home.png)

Android 客户端目前处于测试阶段，可在 GitHub Release 下载测试 APK。Windows 用户也可以下载安装版或便携版；NAS 用户直接使用 Docker 镜像即可。

### NAS / Docker 部署

项目支持把数据保存在自己的服务器或 NAS 中。AMD64 设备可以直接拉取当前版本镜像：

```bash
docker pull ph97/finexy-bookkeeping:1.9.0-amd64
```

完整部署包中提供 Compose 配置和环境变量示例。首次部署需要设置自己的安全密钥；AI 和 OCR 都是可选能力，不配置第三方模型也能使用基础记账功能。

### 适合哪些人

- 希望财务数据保存在自己设备上的自托管用户；
- 想在 NAS 上搭建家庭服务的玩家；
- 需要和家人共同记账，但又希望区分操作权限的人；
- 想把个人、家庭和不同项目分开管理的人；
- 喜欢开源项目，愿意参与测试和反馈的人。
