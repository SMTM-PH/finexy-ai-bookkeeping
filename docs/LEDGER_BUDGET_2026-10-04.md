# 账本月度预算

日期：2026-10-04。承接 [开发计划 M2](DEVELOPMENT_PLAN_STATUS_2026-10-04.md)。本轮在原脏工作树实现服务端、桌面/移动 Web 和 Android 预算；真实发布状态与隔离验证分别记录。

## 合同与范围

- 每个账本每月一份固定币种预算。旧请求未提供账本时仍指默认个人账本 `0`；旧数据增加该默认值。旧预算缺少币种时，迁移一次性固定为所有者当前默认币种，仅作为兼容值，不能推断历史币种。
- 所有有效成员可读，所有者和管理员可保存/清除。共享数据写入账本所有者分片，在事务内复核实际账本及成员权限。普通/只读成员不能通过 API 修改预算。
- `ledgerId`、预算 ID 和分类 ID 使用字符串或 Long，金额为整数最小货币单位，最大 `9999999999999`。分类额度引用所有者有效、可见的末级支出分类，含父级校验；分类是所有者级资源，不虚构分类的账本字段。
- 只计算预算币种的净支出，退款冲减支出；收入、转账和余额调整不占用预算，其他币种不折算。使用完整的当月流水、账户及分类快照，异常或不完整响应不能作为零或未设置。
- GET 的有效 `result: null` 表示未设置。保存回包必须是完整预算，清除必须返回 `true`；失败保留已有数据。
- `revision` 为正的安全整数，写入携带 `expectedRevision`。共享账本必须提供版本，`0` 仅表示预期无活跃预算；默认账本旧客户端可省略。过期保存/清除返回 HTTP 409，实时权限拒绝优先于版本冲突。
- 删除和重新创建继续增加版本，防止旧页面在重建后覆盖新预算。数据库唯一活跃范围约束和条件更新保护多人同时保存。
- 活跃预算进入账本删除预览 `monthlyBudgetCount` 与 `monthlyBudgets` 阻断原因；删除事务再次检查。有预算的空账户账本也不能直接删除，清除预算保留流水及余额。

## 界面与恢复

- 桌面计划页和移动设置 → 月度预算共用面板；桌面首页卡读取当前账本预算与真实币种。切换账本/月度立即停止展示旧目标数据，缓存按服务器路径、用户、账本和月份隔离。
- Web 未保存草稿在当前面板保留并绑定原目标，关闭或重载会丢失且有说明。刷新脏草稿不更新其保存基线。409 保留输入，用户先读取服务器预算核对，再明确采用该版本，最后再次保存。
- Android 预算为在线设置二级页，不另建 Room 预算副本、不改 Room/备份 schema。读取失败、离线、未设置、只读、结果待确认与冲突分别表达。编辑期间禁用月份切换，离开未保存编辑须确认；返回设置保留账本选择。
- 隐藏金额同时隐藏额度、剩余、使用率、进度、输入和无障碍金额语义；采用冲突基线前须显示金额核对。清除/删除有明确账本与月份的确认。
- 生产浏览器发现新增共用面板产生初始化循环后，`MonthlyBudgetPanel` 也归入 Vite common chunk；桌面和移动冷启动须实际挂载登录入口。币种选择框有明确的无障碍名称，不把所有选项拼入名称。
- Android 保留账本选择引出的 AI 关联回归一并修复：现有账号 AI 队列明确归默认个人账本，核对返回先切该目标；切换账本只放弃本轮编辑，待复核记录保留。Room 字典刷新不重复覆盖编辑，保存前校验 AI 关联不可进入共享写入队列。此防线不等于 AI 已完成共享账本合同。
