# 移动 Web 账本写入与恢复

本轮接续 [第一轮修复](FIRST_ITERATION_2026-10-03.md)，范围是移动 Web 当前账本的普通收支、账户间/外部转账、编辑、复制与单笔删除。源码版本仍为 1.9.3；候选构建不是正式发布。Android 主应用、本地用户服务和 NAS 不在本轮更新范围。

## 行为与权限

| 角色 | 新增基础流水 | 修改/删除 | 标签与附件 |
| --- | --- | --- | --- |
| 所有者 | 支持 | 本账本可编辑流水 | 沿用所有者资源合同 |
| 管理员 | 支持 | 仅自己记录且可编辑的流水 | 保留原关联，不增删替换 |
| 普通成员 | 支持 | 仅自己记录且可编辑的流水 | 保留原关联，不增删替换 |
| 只读成员 | 禁止 | 禁止 | 不提供管理操作 |

时间编辑范围、存钱目标资金引用等原有保护继续生效。只读状态来自实时成员权限和服务端 `editable`，不凭页面隐藏按钮作为授权。服务端在修改/删除的财务事务中复核成员、实际账本、账户分片、记账人及转账关联行；非所有者编辑还核对完整标签/附件集合，防止过期快照清除关联。

转账提供“账户间转账 / 转出 / 转入”，账户间转账保留两账户、两币种与两金额；外部转出只涉及来源账户，外部转入只涉及目标账户。显式失效的账户/分类链接显示错误，不静默换成其他账户。非默认账本余额调整、账户管理、完整统计及分类/标签/模板管理仍显示当前客户端能力限制；AI 与模板继续限定默认个人账本。

复制会生成新流水 ID；非所有者复制带所有者标签/附件的流水，先确认去除这些字段或取消。附件不能复用已经绑定的图片 ID，所有者复制同样先确认去除原附件，再允许重新上传；不伪装为附件已经复制成功。

## 草稿与待确认请求

- 本机状态以服务器地址/路径、登录用户名和字符串账本 ID 隔离。默认账本 0 保留兼容语义；旧草稿只迁入原记录的账本。
- 当前账本偏好重载后先用有效账本列表核验，再挂载记账页面。读取失败提供重试页，不把接口失败当成默认账本的成功恢复。
- 草稿是可选偏好：普通新增离开页面时，按“启用”或“确认后保存”设置保存当前账本草稿及稳定请求键；编辑、复制和模板不走此草稿流程。保存完整时间、时区、地理位置、双账户、双金额、标签/附件和备注；切换账本不迁写草稿。待确认请求则在提交前强制保存，不受草稿偏好影响。
- 每个账本一笔待确认新增：请求前先持久化不可变 DTO 与 `clientSessionId`；IndexedDB 写事务串行化跨标签页的短暂本机更新，支持非 HTTPS 的 LAN 地址。
- 请求结果未知时锁住原表单，提供“重试原请求”；重载、另一标签页或不同输入仍回放原快照和键。存储失败、记录损坏或当前账号变化均阻止替代请求。
- 明确成功并完成本机确认后才移除待确认记录；后续列表/余额刷新失败只重试读取。确认只能移除同一请求键，不能清掉另一标签页的新请求。
- 另一标签页已确认并清理请求时，仍收到失败的页面保留实际提交快照与键；再次保存明确回放该快照，不能拿此前不同的表单输入生成替代请求。
- 退出账号清理可选草稿，保留待确认记录供原账号核对；其他账号不能读取。启用、修改或关闭应用 PIN 时同步转换这些状态的加密，转换失败回退原记录。跨设备同步这些本机状态尚未提供。

移动表单通过正常设置界面切换深色主题与最大字号；检查 375px 窄屏、844px 横屏、768/1024/1440px 视口，保存控件至少 44px 且在视口内。最大字号时发现并局部修正记账页标题与返回按钮重叠，生产浏览器另断言标题不覆盖左右操作区。这些自动检查不代替真实软键盘、全流程主题/字体/横屏人工验收或完整读屏。

新增门禁：[生产移动写入](../.github/scripts/verify-mobile-ledger-write.mjs)、存储隔离/加密与待确认请求单元测试、服务端 SQLite 事务及权限竞态专项。现有移动账本上下文门禁已移除本轮接通的普通记账深链限制，继续验证其他未接通功能的保护。

SQLite 同时进行请求预检和财务写入时仍可能返回瞬时 500。本轮观察到此行为，不宣称高并发零失败；客户端保留实际请求供稳定重试。双标签页门禁同时触发本机准备，为确定性故障注入依次递送 HTTP，再故意丢弃第一页响应；另以 CGO race 与八路 HTTP 幂等专项验证服务端并发及稳定重试。

未运行 Android 设备专项、正式签名/升级、远程 CI 或真实服务部署；没有将本轮候选安装到主应用、18080 本地用户服务或 NAS。生产构建仍有弃用及大 chunk 提示，后续拆包须保留 Agent/AI/分类关联组件的 common chunk 初始化约束并重验入口冷启动。

本轮无卷临时服务已清理，候选镜像和本机证据保留。18080 用户服务只读核验仍运行且健康接口返回 200；该检查不扩大为用户业务验收。
