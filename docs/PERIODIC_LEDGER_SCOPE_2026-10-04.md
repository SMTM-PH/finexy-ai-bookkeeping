# 周期计划与账本归属

日期：2026-10-04。承接 [开发计划 M2](DEVELOPMENT_PLAN_STATUS_2026-10-04.md)。本轮实现服务端账本合同及桌面 Web 接入；移动 Web、Android、AI 账本化与真实发布仍有未完成项。

## 服务端合同

- 普通模板、周期模板与到期待确认记录增加明确的 `ledgerId`，旧行及旧请求仍归默认个人账本 `0`。模板 ID、账户 ID、分类 ID、账本 ID 与确认回包流水 ID 使用字符串，不经过 JS 浮点。
- 所有有效成员可读；所有者/管理员管理模板；所有者/管理员/普通成员确认、忽略和恢复到期记录；只读成员不能写。使用直接账本成员关系及所有者数据分片，事务内复核实际账本、当前角色和资源归属。
- 到期派发重新读取持久化模板，核验执行频率、时区及日期，仅生成不可变待确认快照，不改变余额。隐藏继续执行；暂停使用禁用频率。执行时刻仍为模板时区午夜。
- 每天规则接受 Web 的频率占位值 `0` 及既有客户端的 `1`；两者都表示每日当地午夜，不是间隔天数。空值、多值、其他值和非规范数字仍拒绝。生产新建表单曾被新增校验错误拒绝，现已修复并覆盖创建、修改、派发和确认。
- 确认、财务写入和待确认回执在同一事务中完成。实际确认人为 `recorderUid`/`payerUid`，账本所有者为存储 UID；退款冲减支出，内部转账保留两个账户及两个原币整数金额。
- 同一记录的重复确认返回原流水 ID。进程内互斥在查询账本权限之前获取，避免 SQLite 多连接下另一个确认事务锁住成员表后，等待中的请求先查询权限而失败。事务内权限复核及条件更新继续保留。
- 模板删除后保留已捕获记录。待确认/已忽略快照继续保护账户、分类、父分类与标签引用，损坏快照不能作为无引用的依据；已确认记录由真实流水保护引用。
- 账本删除预览增加 `transactionTemplateCount`/`scheduledOccurrenceCount`，阻断原因增加 `transactionTemplates`/`scheduledOccurrences`，删除事务重新检查。
- API 路径保持原有 `transaction/templates/*` 和 `schedule/review/*`，列表/详情使用查询参数 `ledgerId`，写入使用 JSON 字符串 `ledgerId`。Agent 令牌的路由白名单没有扩权，未增加周期 MCP 工具。

## 桌面 Web 合同

- 计划、普通模板及首页周期待确认使用当前账本。切换账本/账号立即清空旧展示并丢弃迟到回包；请求捕获服务器、账号、账本和字段快照，保存前重新读取当前成员权限。
- 完整模板响应校验 ID、账本、类型、金额及重复记录。待确认和已忽略列表分页读完再一起提交缓存，任一页失效均不作为空队列；403/404/异常响应显示失败。
- 普通收支的 API 可以省略零值转账字段；仅在这种合法省略时补零，转账仍要求双侧字段，`null` 等错误字段不能混同省略。模型复制保留分类 getter，标签数组另行复制。
- 只读成员不提供编辑、开关和确认操作。共享模板保留原标签；当前表单暂不支持修改所有者的标签关联，也不借当前成员的私人标签创建关联。
- 金额使用实际账户币种，退款保留符号，跨币种转账同时显示双侧金额；缺少账户或币种显示待核对，金额隐藏继续生效。提醒明确“到期后待确认”，不承诺自动入账。
- 开关有 44px 点击区域和键盘焦点。分类/账户、日期和周期选择菜单每次打开重新创建弹层，避免复用隐藏菜单的固定定位产生重复偏移；需要实际表单验证，构建不能替代。
- 同名普通模板以字符串 ID 标识和修改，不以名称作为卡片 key。到期日历包含隐藏的有效计划；天数、计划数与到期次数分别表达，不用执行次数暗示已入账。下次到期按完整时间排序，注明设备时区。
- 计划与普通模板页面在窄屏调整导航、摘要和面板列数；375px 使用横向工具导航和纵向记录操作，844px 横屏采用单列计划面板。大屏布局保留，读屏、主题和字体完整人工项另行验收。
