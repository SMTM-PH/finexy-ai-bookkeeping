# 移动周期记账接续

日期：2026-10-05。接续 [周期账本合同](PERIODIC_LEDGER_SCOPE_2026-10-04.md)，只记录本轮实际交付。真实服务、NAS 和主 Android 应用均未升级，整个开发计划仍在进行中。

## 本轮实现

- 移动 Web 普通模板、周期计划、待确认和已忽略入口绑定当前账本。所有者/管理员管理模板，可记账成员处理到期记录，只读成员仅查看。读取、选择和操作核验服务器、用户、账本及当前成员权限；共享编辑保留原标签，非所有者应用含标签模板须显式确认去除或取消。
- Android 周期计划/待确认入口使用选定账本；请求和回包检查归属，精确 Long ID、整数最小货币单位、完整列表和财务快照。普通模板的非默认账本页面仍待完成，不能将数据层支持视为界面验收。
- Room 23 以 `(ledgerId, id)` 和 `(ledgerId, templateId, scheduledUnixTime)` 分区。22→23 migration 重建表并保留全部字段，旧缓存归默认账本 0；没有 destructive migration。
- 确认、忽略、恢复先持久化原始账本、模板、到期秒、动作与排队时刻；结果未知不能换动作。列表刷新不删除或覆盖尚待核对的完整快照。回执只确认原上传动作；新进程 SyncWorker 先重试这些动作，再拉取列表。明确成功后刷新失败不会再次入账。
- 备份 schema 17 保留分区及待确认动作，恢复仍只添加缺失行，不覆盖更新的本机记录。schema 8–16 的周期记录归默认账本；本轮补充 schema 13 独立兼容及伪造归属拒绝。
- 页面使用来源账户真实币种，退款冲减支出，转账保留双金额。隐藏金额不输出金额；未知账户/币种显示待核对。暂停保留本机原规则，隐藏与暂停分开。
