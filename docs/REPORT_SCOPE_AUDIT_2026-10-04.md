# M2 五维报告与导出范围审计

日期：2026-10-04。承接 [设计评审](DESIGN_REVIEW_2026-10-02.md) 的 M2，按当前工作树读取源码。本文只审计报告、筛选和导出，不修改功能源码，不安装 APK，不访问真实财务数据，不启动或操作测试服务，不部署。当前预算专项的结果由其交付记录负责，不能扩展为报告已验收。

## 结论与最小交付

当前有可运行的统计和导出实现，五维跨端报告尚未形成完整合同。桌面已有原币种趋势与月度小计 CSV；移动 Web 有默认个人账本的统计、筛选和下钻；Android 有账户页内的五维筛选、图表和 CSV 文本分享；Go 有账本隔离的统计读取及默认账本的明细导出。不能把未接入当前路由的旧组件、原型或已有测试名称视为新报告已交付。

建议下一轮只交付“当前账本的五维只读月报和明细 CSV”：日期、类型、账户、分类、标签共用一个查询，收入/支出/净额、趋势、分类排行、匹配流水、下钻与导出使用同一范围；原币种分组，退款保留符号，转账与余额调整不计入收支。先完成 Go 合同与桌面一条完整流程，再接移动 Web 和 Android。资产历史估值、汇率折算、AI 分析、PDF/Excel、任意探索器和性能大改留到后续。

- [UI/UX 基线](UI_UX_DESIGN.md) 第 9、11.5、11.6 节要求同一筛选作用于图表、汇总、列表和导出，月报数字可以下钻；导出先确认条数和金额，文件的时区、金额与隐藏记录规则一致，失败保留筛选。桌面延续工作台，移动端采用独立子页面；不新增结构性 Tab。
- [第一轮修复](FIRST_ITERATION_2026-10-03.md) 已记录桌面原币种汇总、月度 CSV、错误保护和浏览器专项；该文明确“完整五维报告留后续”。移动写入的最新范围由 [2026-10-04 专项](MOBILE_LEDGER_WRITE_2026-10-04.md) 修正，不能照抄旧文的写入限制；完整统计仍受现行深链保护。
- 下表“已实现”指当前源码具有实际调用路径；“历史验证”只引用既有记录；“缺口/风险”由静态读取得出。本轮未运行报告功能测试、浏览器、设备、隔离 HTTP、时区或容量专项，也未核验真实部署版本。

### Android：已有筛选流程，需要换用结构化财务数据

1. [Activity 模型及转换](../android/app/src/main/java/com/finexy/mobile/MainActivity.kt) 68、863 行已包含 `sourceAmountMinor`、`destinationAmountMinor`、币种、账户、分类 ID、时间和偏移；报告应读取这些结构化字段，不必新增另一份金额文本存储。
2. [StatisticsCard](../android/app/src/main/java/com/finexy/mobile/FinexyScreens.kt) 825–922 行的五维筛选、图表和导出确认共用行集合，是真实流程。该文件 73–75 行 `money()` 固定 `¥`，`parseAmountForUi()` 去掉正负号；845、899、913、966、993 行统计解析文本为 `Double`，解析失败用零。负支出退款因此会失去负号，混合币种被直接相加；这是明确源码路径，本轮没有运行新的退款/混币设备复现。
3. 同文件 948–956 行 CSV 有日期、类型、分类、账户 ID、金额、描述、标签，正确转义双引号；没有币种、单位、服务器 ID、目标账户/币种/金额，转账文本可能输出 `10.00 → 20.00` 而非两侧结构化数值。`ACTION_SEND + EXTRA_TEXT` 是文本分享，不是已验证的文件写入/取消/失败恢复流程。
4. 同文件 835–840、925–928 行按分类名称匹配，默认偏好先从 ID 映射回名字。同名父/子分类会混在一起；隐去的历史账户不能仅因为账户选择器不可见而丢失实际币种元数据。标签可多选关联，一条流水可以进入多个标签组，应说明组间合计不可直接相加。
5. 同文件 939–946 行近 N 日截止点按 Calendar 设备自然日计算，已有上海时区测试；959 行 7 日趋势却按固定 24 小时减天，在 DST 地区可能与自然日边界不一致。6 月趋势围绕当前月，标签仅“MM月”；需支持年份、上界和查询内范围。
6. [MainActivity](../android/app/src/main/java/com/finexy/mobile/MainActivity.kt) 225–242、423 行从 Repository Flow 选择当前账本；586 行共享账本把标签传空，却传 `roomCategories` 和个人默认统计过滤。报告必须使用当前账本字典，切换清理不兼容过滤并说明，不能把旧过滤造成的空集解释为新账本没有数据。
7. [Repository 快照](../android/app/src/main/java/com/finexy/mobile/data/TransactionRepository.kt) 102 行已校验共享流水实际账本、ID 和时间单位，在事务中替换缓存；[FinexyApi 分页](../android/app/src/main/java/com/finexy/mobile/data/FinexyApi.kt) 49、1184 行有逐页游标与去重。新报告还须明确同步中/失败/离线快照来源和完成时间，不把 Room Flow 的初始空列表当成服务器真实空态。`Activity` 未携带原流水 `hideAmount`，报告隐藏规则应从原 Entity 保留，不通过转换丢失。

### Go：统一查询可复用，导出必须增加账本合同

1. [流水模型](../pkg/models/transaction.go) 的列表 DTO 已有五维查询及 `ledgerId`；[服务读取](../pkg/services/transactions.go) 494、616、3149 行可复用账本校验、账户/分类过滤和标签语义，采用实际数据所有者 UID，不能按名称或当前登录用户账户推断。
2. [统计 DTO](../pkg/models/transaction.go) 311–339、485–505 行：分类统计与月趋势有账本、时间、标签、关键词、交易时区开关，响应是账户/分类 ID 与整数 `amount`，没有匹配笔数、币种或完整性。不能通过前端给 URL 添加 `type/account_ids/category_ids` 就宣称服务端已过滤。
3. [统计服务](../pkg/services/transactions.go) 2573、2714 行使用 `GetLedgerWithAccess(..., anyFamilyRole)` 和账本所有者分片，读取权限基础已存在；聚合按账户/分类及转账方向。`totalAmounts.Amount += transaction.Amount` 等使用 `int64` 无溢出保护，新增汇总应使用显式检查或可安全表示的十进制字符串，超限可见且禁止导出不完整结果。
4. [数据导出 DTO](../pkg/models/data_management.go) 29 行没有账本；[导出 handler](../pkg/api/data_managements.go) 494–618 行取当前用户账户/分类/标签、展开其资源 ID，并调用 `GetAllSpecifiedTransactions`。[该读取](../pkg/services/transactions.go) 434 行明确 `ledger_id=0`。这份账号数据导出不能承担共享报表导出，也不能默认忽略一个新传入的账本参数。
5. [现有转换器](../pkg/converters/default/default_transaction_data_plain_text_converter.go) 已带账户币种、目标币种及双金额；[明细 exporter](../pkg/converters/converter/data_table_transaction_data_exporter.go) 21–77 行处理转账双记录去重、原金额格式与记录时区。应保留其导入兼容格式；报告 CSV 另定义展示时区列，不能直接替换原交易时区后破坏既有备份/导入用途。
6. [标签列表](../pkg/api/transaction_tags.go) 28 行仍是登录用户 UID 的账号资源。五维共享报告需新增或扩展“当前账本可读标签字典”：仅暴露该账本可见关联及经授权的名称，不开放所有者其他账本标签，不自动赋予成员标签管理权限。无标签过滤与 AND/OR 等既有合同要保持一致。
7. 资产趋势 DTO 没有账本，读取路径属于原账号合同。M2 月报不顺带开放共享资产历史图，避免错误扩大能力。

## 建议统一合同

首版在现有账本流水查询上抽出一个规范化查询，按以下规则实现，不要求重写旧统计/账号导出。可以新增专用报告读取、导出预览与 CSV 端点，或扩展既有接口；选择以复用真实过滤实现和兼容旧调用为准。

| 合同部分 | 首版要求 |
| --- | --- |
| 身份与范围 | 缓存/请求键为服务器、登录用户、字符串账本 ID、规范化查询；默认 `0` 保留个人语义。异步完成前核对捕获身份与查询，读权限在服务端复核 |
| 日期 | 设备 IANA 时区、日期闭区间规范化为 `[start, endExclusive)`；API Unix 秒、Android Room 毫秒。同一范围用于统计/流水/CSV，不以固定 24 小时推算自然日 |
| 类型 | 沿用 0 全部、1 余额调整、2 收入、3 支出、4 转账；筛选条数与明细覆盖所选类型，收支合计只计算收入/支出。转账按一笔用户流水去重并保留双侧金额 |
| 账户与分类 | 用 ID 数组及明确包含/排除语义，父级展开校验实际账本；账户筛选含源或目标；分类用 ID 分组，显示可带父路径，同名不合并 |
| 标签 | 仅当前账本可读字典，沿用既有无标签与匹配模式；选择空集和“未过滤”不能混淆；非所有者读取不等于管理授权 |
| 币种与金额 | 原账户币种、带符号整数最小单位，明确主单位两位小数；无隐式汇率。币种选择若是查询条件，必须同时影响流水与导出；若只是分组显示，必须明确说明，不能让各模块自行解释 |
| 返回结果 | 回显规范化查询和匹配笔数；收入/支出/净额按币种、趋势、分类排行来自同一匹配集合；真实空、失败、超限、缺元数据、未完整读取分别可辨 |
| 下钻 | 从月度/分类/数字进入流水时保留其余维度、账本、时区与币种，仅增添该维度约束；返回继续使用原筛选，不静默变成当前月 |
| 导出 | 预览与导出绑定同一查询和数据版本/快照；下载前确认明细条数、日期、币种/分组金额与隐藏记录规则。确认期间身份/账本/过滤或数据基线变化需重新核对，不能自动换目标 |
| 隐藏与失败 | 不凭隐藏账户状态清除历史记录；显式确定隐藏记录包含规则，并让图/合计/列表/CSV一致。金额隐藏不能通过图表比例、确认文案或辅助标签泄漏；导出原始金额需明确展示动作。读取/分享/下载失败保留查询，不能伪装成功或空集 |

共享账本报告读取沿用四角色均可读；导出还需执行现有用户导出限制。若增加独立的共享导出权限，应先落实服务端合同，客户端不要把客户端暂未支持说成成员无权限。报表不修改流水/余额；不新增 Room 财务副本。

## 分批开发顺序与出口

1. **查询与服务端切片**：固化跨端合成夹具；共用账本过滤、标签字典、退款/转账/调整语义和时区；补报告结果完整性、溢出及导出预览/CSV。CGO=1 事务/成员隔离测试和真实 HTTP 专项通过后，才能开放共享入口。
2. **桌面完整切片**：提取局部报告查询/展示组件，保留工作台 Shell 与现有原币种金额修复；五维固定顺序，月报、环比、分类排行和流水下钻；明细导出绑定预览。生产浏览器验证旧统计深链被明确迁移/兼容，不能只是路由仍有 props。
3. **移动 Web 接入**：用同一服务合同接 F7 独立报告子页，完成账本/用户隔离、窄屏筛选和可见重试；通过共享四角色及深链验收后再放开能力守卫，不扩大账户/分类/标签管理权限。
4. **Android 接入**：用 Entity 的 ID、币种、整数金额替换文本解析；当前账本元数据与同步状态；报告从总览/账户进入子页，保留 Room Flow；CSV 通过可核对的文件/分享动作导出并处理失败/取消，补独立 QA 专项。
5. **收尾**：同一候选提交的跨端合成夹具期望值一致；完成键盘、窄屏、最大字体、深浅主题与读屏专项，记录未运行项；按已有授权分别安排主应用升级与真实服务部署，不能因审计文档附带发布。

每一切片可以独立审查，但 M2 五维报告的完成条件是四端合同及实际入口一致，不能仅把前两项完成当作全端交付。

## 隔离验收方案

### 共用数据集与财务断言

仅使用无卷一次性服务、随机账号和合成数据；默认账本与 A/B 共享账本均准备所有者、管理员、记账成员、只读成员。服务器镜像、容器挂载、注册开关和 UUID 实例号操作前核验；不得对本地用户服务或 NAS 运行以下测试。

- 日期：跨年、月底/闰日、边界秒、上海/UTC/有 DST 的 IANA 时区；交易保存偏移与设备时区不同。下界包含、上界排除，趋势桶/列表日期/CSV对应一致。
- 财务：CNY/USD 分组、最小单位 1、负支出退款、全额/超额退款、余额调整、内部/外部转账、跨币种双金额；缺账户/分类、非法金额与聚合超限只能是不完整，不能成为默认币种或零。
- 资源：同名不同 ID 分类、父级/末级账户、隐藏父/子账户与历史记录、无标签/多标签/AND/OR、其他账本或其他用户资源；每个维度单独及五维组合，全部组件和导出匹配 ID 集合一致。
- 完整性：超过一页、同秒多笔、坏/缺 `result`、错误计数、重复/跨账本记录、游标不前进、503、权限被撤回。已加载快照来源明确，不用部分分页结果产生完整报告。

### 服务端与浏览器

- CGO=1 验证成员读权限、所有者分片、资源归属和金额边界；HTTP 验证匿名/非成员拒绝、四角色报告可读、导出限制、A/B/默认隔离、筛选与 CSV 行集合完全匹配。
- 桌面与移动实际生产入口完成月报 → 五维变更 → 数字下钻 → 返回 → 导出预览 → 确认下载；取消不导出。预览期间换账本/用户/过滤或远端变化拒绝旧确认；慢 A 响应不覆盖 B，失败重试保持查询。
- CSV 重新解析核对行数、原 ID、类型、来源/目标账户和币种、带符号金额、年份/时区及用户文本转义；含换行、逗号、双引号与公式开头文本的单元格专项。主单位不能误成最小单位，不凭文件下载成功代替内容核对。
- 金额隐藏 DOM/ARIA、键盘操作、至少 44px 目标、窄屏和大字号实际可达；图表数值表可读，负净额不用错误柱高/百分比，空集无虚假图形。
