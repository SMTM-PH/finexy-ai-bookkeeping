# Android 模板创建：生产表单与本机恢复入口

日期：2026-10-05。接续 [存储底座](TEMPLATE_CREATION_ANDROID_STORAGE_2026-10-05.md) 和 [生产 API / Worker](TEMPLATE_CREATION_ANDROID_WORKER_2026-10-05.md)。范围为普通模板管理页、周期计划管理页的原始表单、明确确认、原请求重试与活动重建；不升级主应用或真实服务。

## 页面合同

- 普通模板仍归设置二级页，周期计划仍使用原入口；两者绑定打开时的账本和当前服务器/用户数据库，不新增导航层级。
- `TemplateDraftSession` 串行保存完整原始字符串。空名称、不完整金额、未完成日期和时区均可保存；账户/分类用字符串 ID，不经过浮点。页面已开始的本机保存不会因导航取消而中断，保存失败显示错误并提供重试，确认前必须等最新版本保存完成。
- 取消弹窗保留已经保存的草稿；页面提供“继续编辑上次草稿”和有二次确认的“丢弃草稿”。原模板已经不在当前有效列表中时停止恢复编辑，保留草稿并要求重新读取；不将已有模板草稿变成新增。
- 普通模板保存名称、类型、退款、双金额、双账户、分类、备注、标签和金额隐藏；周期计划另存完整规则、日期与时区。恢复后仍校验当前账本可用资源，不能凭名称重新映射。修改已有模板保留原 ID，沿用独立修改接口，不进入新增队列。
- 预览不上传。用户明确确认新增后，先事务保存不可变请求、原账本及稳定键，再调度 WorkManager，最后尝试前台投递。旧服务端不支持持久合同时保留原请求，不回退旧新增接口。
- 未确认结果展示“重试原请求”，此账本/类型的新增、替代编辑与草稿丢弃被阻止；回执已经保存时只显示“重新读取创建结果”。当前账本其他模板和另一类型的独立请求不替换该请求。完整刷新才清理匹配版本的草稿与队列。
- 草稿保留不授予管理权限；成员权限撤销后隐藏继续编辑/丢弃入口并说明草稿仍保留。发送仍由正常会话实时复核成员权限，恢复管理权限后才能继续处理。
- 周期表单金额使用实际账户币种与整数最小货币单位，种子显示不经过 Double。同币种转账联动双金额，跨币种保留两侧输入，负支出表示退款。账户无障碍名称包含方向、币种和 ID；完整 TalkBack 验收仍待完成。

本轮不改变 Room 24、备份 schema 18 或产品版本。生产改动在 `TemplateDraftSession.kt`、`NormalTemplateScreens.kt`、`ScheduleScreens.kt` 和共用 `TemplateEditorDialog`；非导出 QA 登录宿主保持命名空间与数据库清理名单跨活动重建。
