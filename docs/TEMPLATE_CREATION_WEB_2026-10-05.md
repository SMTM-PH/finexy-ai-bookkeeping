## 已实现的数据层

- `src/models/template_creation.ts` 定义原始编辑输入、带版本/修订号的草稿、用户已确认的不可变请求及最小成功回执。未完成金额文本（例如 `1.`、空字符串）、空名称与未选分类可以作为草稿保留；确认请求必须使用整数最小货币单位、字符串 ID、完整日历/时区及最多 128 字节的稳定键。非法日期和周期规则不能被静默归一化后冻结。
- `src/lib/userstate.ts` 复用现有服务器 origin/路径、用户名及账本分区；普通/周期草稿分开，确认队列每账本一份。模板记录随应用锁的启用、改 PIN 和解除锁一同重新加密；模板草稿和未知结果在退出登录后保留，仅原账号可恢复。存储损坏、配额不足及锁未解开均失败关闭，不作为空队列。
- `src/stores/templateCreation.ts` 使用现有 IndexedDB 跨标签页短事务锁。草稿保存/丢弃检查原修订号；确认前检查当前账号、账本与实时管理权限。明确确认先保存完整快照，再检查服务能力，再调用专用接口；并非在恢复草稿时自动发送。
- 新增服务调用 `getTemplateCreationCapabilities` / `addDurableTransactionTemplate`。每次未知结果重试都重新核验服务合同；旧服务 404 或合同缺失提示升级并保留原请求，不调用旧 `add.json` 替代。能力必须明确承诺版本 1、内容绑定、删除回执、账本/创建人分区和专用路径。
- 未知结果保留原键、双账户/双金额、标签、隐藏金额、备注和完整周期输入，禁止替代新增及丢弃。成功先保存原模板字符串 ID 和删除状态；已有回执的重试不再 POST，读取失败由后续页面只重试读取。回包验证账本、类型、结构和删除状态；删除回执不作为可编辑新模板。
- 账本选择在回包期间变化时，明确回执仍保存到原账本；账号变化时不写新账号。处理完成只清理匹配请求及已确认草稿修订，不删除未来的新编辑。调用者不会收到创建请求失败中的 Axios 配置或认证头。

## 已接通的生产页面

- 桌面共享 `transactions/list/dialogs/EditDialog.vue`、移动 `transactions/EditPage.vue` 的普通/周期新增均使用 `TemplateCreationPanel`。已有模板编辑沿用实际 ID 的修改接口，未将修改改成创建重放。
- 输入变化保存本机草稿；状态明确区分核验中、保存中、已保存、失败和可恢复。恢复入口须明确点击“继续编辑已保存草稿”；丢弃有第二次确认。预览等待最新草稿保存完成，显示明确账本、名称、实际账户币种与周期规则；点击“确认创建模板”才冻结并发送。
- 桌面金额控件保留小数点、空输入和未计算表达式；手机计算器保留当前数字、前一数字、运算符及是否确认。未计算/未确认内容可保存为草稿，不能当作整数请求上传。类别切换保留三个类型的分类选择，恢复采用原字符串 ID。
- 未知结果锁定表单，提供“重试原请求”；成功回执遇到读取失败则提供“重新读取原模板”，不再次 POST。删除回执或完整有效列表确认原 ID 已不存在时提示原模板已删除，不替代新增。
- 另一标签页通过真实 StorageEvent 接收原请求状态；已有预览随之锁定。另一页已处理后提示返回列表核对，并允许关闭当前编辑器；修复了旧错误仍阻止取消的问题。异步保存/回包检查页面代次，不能关闭后来打开的编辑器或替换其修订号。
- 面板沿用主题与字号变量、可见错误、状态/警报语义和至少 44px 操作目标；状态段保留最小高度，允许最大字号自然增高。

数据层单元测试与生产浏览器结果分别记录，不将模拟网络/锁的单测算成页面验收。
