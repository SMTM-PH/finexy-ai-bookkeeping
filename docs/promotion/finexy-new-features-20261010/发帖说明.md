# 发帖说明

`论坛推广.md` 为正文，`images/` 为配套图片。图片直接复制自已检查的隔离验收截图，未重新绘制、拼接或修改界面。正文和图片均未包含真实用户财务数据、完整令牌、密码或密钥。

## 发布方法

1. 复制 `论坛推广.md` 到论坛 Markdown 编辑器。
2. 按正文顺序上传 `images/` 内的 8 张图片。
3. 将正文里的 `images/01-dashboard.png` 等相对路径替换为论坛返回的图片链接。相对路径供本地 Markdown 预览使用，直接粘贴到论坛不会自动上传图片。
4. 检查图片显示、标题和链接；保留开头的版本说明以及开发预览图注。

若论坛篇幅有限，可保留账单导入、AI 复核、Agent 授权与账户卡片四部分，省略预算和周期详细介绍。配套 ZIP 仅包含本目录正文、说明与图片，没有测试日志、数据库或应用安装包。
