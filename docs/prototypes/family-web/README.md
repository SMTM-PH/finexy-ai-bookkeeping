# 家庭记账 Web 交互原型

本目录为设计提案，不是生产 Web 功能。仅使用内存演示数据，刷新后重置；没有 API、持久化、真实邀请、AI 调用或银行转账。不要录入真实财务信息。

## 预览

从仓库根目录运行：

```powershell
python -m http.server 18766 --bind 127.0.0.1 --directory docs/prototypes/family-web
```

浏览器打开 `http://127.0.0.1:18766/`。

也可以独立构建 Docker 演示镜像：

```powershell
docker build -t finexy-family-web-prototype docs/prototypes/family-web
docker run --rm -p 18766:8080 finexy-family-web-prototype
```

## 可操作范围

- 顶部切换个人 / 家庭账本，各自流水、预算和余额隔离。
- 总览、流水、账户、预算、家庭管理，以及操作记录子页面。
- 支出、收入、成员投入；公共账户付款与个人垫付；付款人与记账人分离。
- 演示新增 / 编辑更新汇总；垫款报销只改变余额与待报销，不重复统计支出；已报销记录锁定编辑。
- 周期支出确认后才入账，不能再次确认。
- 付款人 / 付款方式 / 文字组合筛选、空态与重置。
- 总预算调整、一次性邀请状态演示与确认撤销、成员角色调整。
- 顶部身份选择器用于检查所有者、普通成员、只读成员交互，不是身份认证。
- 宽屏列表与详情并排；窄于 1160px 使用原型紧凑视图，小屏为卡片列表。不是已集成的 Framework7 页面。

## 设计与验证

沿用 `docs/UI_UX_DESIGN.md` 的珊瑚色、墨黑操作按钮、中性背景、中文字体和数字字体。协作识别重点为付款人 → 家庭账本关系及独立记账人署名；不通过公开个人账户实现共同记账。

使用 Playwright CLI（预览服务需已运行）：

```powershell
playwright-cli -s=family open http://127.0.0.1:18766/
playwright-cli -s=family run-code --filename=docs/prototypes/family-web/verify.cjs
```
